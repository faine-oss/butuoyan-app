# 不拖延 V0.6.0 · 稳定性与长期使用升级

Android 正式签名版：V0.6.0（Build 10），支持 Android 7.0 及以上。

## 本次更新

- 专注计时按结束时间恢复，切换模块或重新打开后继续计算；到点等待确认，仅点击完成后推进关联子任务。
- DDL 支持具体截止时刻，按剩余可用时间评估风险；重排保留完成记录及用户修改过的未完成步骤，不再丢弃中间步骤。
- 计划书支持约 300 DPI 图片导出；四宫格、九宫格超量任务与备注自动续页，PDF 包含全部页面，图片可选择页码。
- 任务中心新增搜索、今天/逾期/未来筛选、安排到明天、回收站与撤销删除。
- 本地草稿保存失败时显示重试与应急导出入口；专注和 DDL 历史不再按旧限制自动清理，支持月份筛选与分页。
- 新增截止前提醒；点击通知进入对应任务。最早 48 项未来提醒在打开应用和任务更新时刷新。

## 安装与注意事项

安装前请在“我的 → 数据安全与备份”导出完整备份。V0.3 及之后的正式版使用相同证书，可直接覆盖安装，不要先卸载。早期 V0.2 调试签名包不能直接覆盖升级。

数据仍保存在本机，不需要登录。应急导出是未保存草稿的恢复资料，不是完整备份；旧版本已清理的历史无法恢复。通知采用系统非精确提醒，可能受锁屏、省电策略影响；覆盖安装、通知跳转和实际打印仍需真机验证。
